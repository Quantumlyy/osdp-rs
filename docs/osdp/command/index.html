Typed OSDP commands (ACU → PD).

§Spec: §6 / Annex A.1

Each command is a strongly-typed Rust value; encoding to wire bytes goes through Command::encode_data and decoding through Command::decode. CommandCode is the byte enum from Annex A.1.
